
# 🩺 Diabetes Early Diagnosis Using Machine Learning

An AI-powered diabetes risk screening application that uses Machine Learning to estimate the likelihood of diabetes based on selected health measurements.

## 🌐 Live Application

**Try the application:**  
https://diabetes-early-diagnosis.streamlit.app/

**GitHub Repository:**  
https://github.com/VivekVaii/diabetes-early-diagnosis

## 📌 Project Overview

Diabetes is a chronic health condition that requires early identification and proper medical attention.

This project demonstrates how Machine Learning can support preliminary diabetes risk screening by analyzing health-related parameters and generating a predicted risk category.

The application provides an interactive interface built using Streamlit.

**Note:** This is an educational research prototype and is not intended to replace professional medical diagnosis.

## 🎯 Objectives

- Explore the application of AI and Machine Learning in healthcare.
- Estimate diabetes risk using health-related measurements.
- Develop an interactive prediction application.
- Demonstrate the use of a trained Machine Learning model.
- Support research into early disease-risk screening.

## 📊 Input Features

The application accepts the following eight health-related parameters:

1. Pregnancies
2. Glucose
3. Blood Pressure
4. Skin Thickness
5. Insulin
6. BMI
7. Diabetes Pedigree Function
8. Age

## 🚀 Application Workflow

1. User enters health measurements.
2. Input values are organized into a Pandas DataFrame.
3. The trained Machine Learning model processes the inputs.
4. The model estimates the probability of the positive class.
5. A classification threshold is applied.
6. The application displays the estimated risk category.
