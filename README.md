# Diabetes model — Streamlit deployment starter

## 1. Create the trained model file
Run the notebook through its final holdout evaluation cell. Then run the export cell
provided in the ChatGPT instructions. It creates `diabetes_model.joblib`.

## 2. Arrange files
Keep these files together in one GitHub repository:
- `app.py`
- `requirements.txt`
- `diabetes_model.joblib`

## 3. Deploy
On Streamlit Community Cloud, create an app from the GitHub repository,
select `app.py` as the main file, and deploy.

This is an educational research prototype, not a medical diagnostic device.
